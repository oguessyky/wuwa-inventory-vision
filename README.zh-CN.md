# WuWa Inventory Vision（鸣潮背包识别）

[English](README.md) · **中文**

**图文使用指南：** <https://oguessyky.github.io/wuwa-inventory-vision/>

**一个帮鸣潮玩家看清背包的免费小工具。** 你在游戏里把背包从头到尾滚一遍，它就从屏幕上读出每样物品和数量。
然后告诉你：手上的东西能养成多少、每个共鸣者和武器还差什么、哪些材料不够、下一步该刷什么或买什么。
它运行在你自己的电脑上（Windows 或 Mac），结果也能在手机上看。它只看屏幕：不碰游戏文件、内存和网络通信，
也绝不替你玩游戏。

![总览：钱包和扫描、现有经验能养成多少、这轮去买什么、缺什么](docs/screens/dashboard.png)

## 它能帮你做什么

- **不用再手动数。** 打开背包，滚动每个分页，按 F9。每样物品的名称、稀有度和数量都会读出来；武器还会读等级、
  谐振和装配在谁身上。游戏自己显示的物品数会告诉它这次扫描有没有扫全。
- **下一步该刷什么。** 每种养成材料对照每个配置，合成也算进去：每个共鸣者和武器还要什么，全部加起来缺多少。
- **规划和采购。** 给共鸣者或武器从现在的等级规划到目标；看每个商店卖什么、限购和价格，以及哪些东西快用完了。
- **手机也能用，中英文都有。** 每一页都适配手机，都有中文和英文版；中文、拼音、首字母、英文都能搜到。

## 安全吗？

它**只读屏幕像素**：不读内存、不注入、不抓包、不改游戏。它做的任何事都不会改变你的账号，也不会移动角色或战斗。
你的玩家 ID 会在每张图保存或显示之前被抹掉。所有东西都留在你自己的电脑上；只有几次会用到网络
（下载物品图鉴、更新程序），每一次都由你自己发起。[隐私政策](PRIVACY.zh-CN.md)写得很清楚。

## 各个页面

| | |
|---|---|
| **总览** | 打开就是这一页：钱包和扫描、现有经验能养成多少、这轮去买什么、缺什么 |
| **库存** | 你拥有的一切，跨扫描合并、可搜索，每样东西从哪来、用在哪 |
| **材料** | 每种养成材料对照完整配置，合成算进去，也能设自己的目标 |
| **共鸣者** 和 **武器** | 有谁、有什么、练到哪、还要什么、谁拿着哪把武器 |
| **料理** | 料理和药剂对照你想留的数量，以及现在能做什么 |
| **商店** | 按地区看每个商店的货架：限购、价格，以及每样东西至少想留多少 |
| **规划** | 从现在的等级规划到目标，和你的库存一起算总账 |
| **猜谜** | 每日小游戏：从图鉴里的资料猜出是哪位共鸣者 |
| **更新** | 版本更新后拉取图鉴、导入抽卡记录、改正 Wiki 写错的地方 |

## 开始使用

从[发布页](https://github.com/oguessyky/wuwa-inventory-vision/releases)下载一个程序包。每个包里都有一份
`START-HERE` 图文指南，每一步都配了图。

| 程序包 | 适合 |
|---|---|
| **full** | 全部装在一台 Windows 电脑上：扫描和页面 |
| **scanner** | 装在玩游戏的电脑上，把每次扫描发给「主机」 |
| **home** | 把页面放在 NAS 或一直开着的机器上，手机随时能打开 |
| **mac-full** / **mac-scanner** | 前两个的 Mac 版 |

在电脑或 Mac 上，每一步都是双击一个文件：安装、扫描、打开页面。扫描端的主机比它新时，双击
`4 更新 Update` 就能自己更新。

**需要什么：** Windows 10/11，或装了库洛官方 Mac 客户端的 macOS；大约 6 GB 硬盘空间。有 NVIDIA 显卡识别会快很多，
但不是必需的。Windows 的程序包里已经带了 Python；Mac 上请先 `brew install python@3.12`。主机需要 Docker 和一个
（免费的）Tailscale 账号。

在 Windows 上的简短做法（在项目文件夹里打开终端）：

```bash
powershell -ExecutionPolicy Bypass -File setup.ps1
```

```bash
uv run python -m wuwa_vision live --identify
```

```bash
uv run python -m wuwa_vision serve
```

第一行安装（Mac 上用 `./setup.sh`）。第二行扫描：切到游戏，滚动背包，扫完按 **F9**。第三行在
<http://127.0.0.1:4000> 打开页面。详细说明见 [docs/setup.md](docs/setup.md)、[docs/scanning.md](docs/scanning.md)、
[docs/dashboard.md](docs/dashboard.md) 和 [docs/nas.md](docs/nas.md)（英文）。

Windows（实机 2560×1600；21:9 等其他尺寸用回放截图测试，不依赖固定的屏幕尺寸）和 macOS（库洛官方 Mac 客户端）
都测试过。在 Mac 上它只读不点，并需要「屏幕录制」权限。

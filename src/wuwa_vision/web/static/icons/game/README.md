# Your own weapon-type icons go here

This folder is empty on purpose.

The app ships five drawings of its own for the weapon types (`../wp-*.svg`: 长刃, 迅刀, 佩枪,
臂铠, 音感仪). If you would rather see other pictures -- the game's own, for instance, if you
have them -- put them here under these names and they are shown instead, with no other change:

    wp-broadblade.webp   长刃
    wp-sword.webp        迅刀
    wp-pistols.webp      佩枪
    wp-gauntlets.webp    臂铠
    wp-rectifier.webp    音感仪

The same names in `data/catalogue/avatars/` work too, and come first.

Nothing from *Wuthering Waves* is shipped in this folder, and nothing should be committed to
it: the game's pictures belong to Kuro Games, and this project does not distribute them
(`CREDITS.md`; D140). What you put here stays on your own machine.

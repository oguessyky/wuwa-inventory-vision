Where the data comes from

None of it is bundled: it is downloaded to your computer only when you run the setup, or press the button on the Update page.

Kuro Games' wiki (库街区 鸣潮WIKI)
The catalogue: names, rarities and icons of items, dishes, weapons and resonators; recipes; what maxing takes; resonator art and head icons; element icons; the Shell Credit icon; boss portraits.
wuwatracker.com (an unofficial fan-made site)
Nothing is downloaded from it. The Update page can read the pull-history file you export from it yourself; that file's format is wuwatracker's.
Arikatsu/WutheringWaves_Data (a game-data repository on GitHub)
The EXP tables for resonator, weapon and echo levels; the shops' goods, limits, prices and places; every English name (the game's own English text, which the search boxes find things by); and the check on what maxing takes -- where the official wiki has a row wrong, it is corrected to what the game charges. The repository states no licence; the data in it is the game's.

The English names of the game's places and factions on the Guess page are the game's own words, checked in the game by hand.

The images and data obtained this way remain Kuro Games'. Thanks to the people who maintain these sources, and to wuwatracker for a pull history that can be exported at all.

Interface icons

The nine page icons of the phone's bar and menu, and the five weapon-type icons (Broadblade, Sword, Pistols, Gauntlets, Rectifier), were made for this tool. To use your own pictures for the weapon types, put files of the same names in the folder the app keeps for them. The other line icons (dish effects, search, filters, the menu button) are taken or adapted from two open-source icon sets, and a few simple ones were drawn in the same style. None of these icons comes from the game; the element icons and portraits are the game's, from the official wiki above.

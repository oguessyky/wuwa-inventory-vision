Help

How to start, what each page is for, and what to do when something goes wrong.

Four steps to start

  1. > powershell -ExecutionPolicy Bypass -File setup.ps1
    1

    Set up

    Run it in the project folder, once.

  2. Update from the wikiUpdate from the wiki● Done
    2

    Update the catalogue

    Once after every game update.

  3. > uv run python -m wuwa_vision live --identify
    Alt+Tab→→F9
    3

    Scan the bag

    Switch to the game and scroll slowly; click items for exact counts; F9 ends it.

  4. 4

    See the results

    Overview for the whole picture, Inventory for each thing, Materials for what is short.

When something goes wrong

BrowserWuthering Waves✓The scan stops at once, or says the window is wrong
  1. The game itself has to be in front: a browser tab of the same name does not count. Check first:
    > uv run python -m wuwa_vision windows
  2. Start scanning once you see guard: window OK.
  3. After it starts you have 60 seconds: press Alt + Tab to switch to the game. Away too long (2 minutes) and it stops; what it read is kept.
F9→F10It says F9 is taken and will not start
  1. Another program has F9. The terminal lists the keys that are free.
  2. Start with another key:
    > uv run python -m wuwa_vision live --identify --panic-key F10
?→✓A tile is red, or its name is a question mark
  1. Some items have identical icons: only clicking tells them apart.
  2. Click the item in the game and wait for the top of the scan page to say Ready
  3. Once clicked it is remembered: no need next time.
?→Update from the wiki→✓Items from a new version have no names
  1. The catalogue is out of date: go to Update → Catalogue and click "Update from the wiki".
  2. Back in the game, click those items.
12→15A count is wrong
  1. Click the item in Inventory.
  2. Click the number, change it, Enter saves.
  3. Your number stays until the next scan reads the item.
Reading…↓ReadyClicking an item takes seconds
  1. Normal: reading the details panel on the right takes about 2.5–3 seconds.
  2. Click the next one once you see Ready.
✕ blocked by Application Control✓ python -m wuwa_vision"wuwa" or python will not start: blocked by a policy
  1. Run it as a module instead of wuwa:
    > uv run python -m wuwa_vision live --identify
  2. If python itself is blocked: install Python 3.12 from python.org, then set up again:
    > powershell -ExecutionPolicy Bypass -File setup.ps1
Screen RecordingNothing is captured on a Mac
  1. System Settings → Privacy & Security → Screen Recording: turn on your terminal.
  2. Quit the terminal and open it again, then check:
    > uv run python -m wuwa_vision platform
TailscaleThe phone cannot open the site
  1. Install Tailscale on both the PC and the phone, signed in to the same account.
  2. Start it without --local:
    > uv run python -m wuwa_vision serve
  3. Open the address it prints on the phone.
WuWa!The page is blank, or says it is not built
  1. The setup did not finish: run it again:
    > powershell -ExecutionPolicy Bypass -File setup.ps1
  2. If you are changing the code:
    > cd web && npm run build

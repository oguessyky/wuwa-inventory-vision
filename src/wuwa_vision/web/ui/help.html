出了问题怎么办

Smart App Control→解除锁定智能应用控制拦下了文件，没有「运行」按钮
  1. 没解除锁定就运行 .cmd，新版 Windows 11 才会弹出这个。不用关掉智能应用控制。
  2. 右键被拦下的文件 → 属性 → 勾选最下面的「解除锁定」→ 确定，再打开它。每个 .cmd 都做一次。
  3. 还没扫描过的话，也可以重来：删掉解压出来的文件夹，右键下载的压缩包 → 属性 → 勾选「解除锁定」，再解压一次。扫描过的话别删：里面有你的数据。
浏览器鸣潮✓扫描一开始就停了，或说窗口不对
  1. 游戏本身要在最前面：浏览器里同名的标签页不算。先检查一下：
    > uv run python -m wuwa_vision windows
  2. 看到 guard: window OK 再开始扫描。
  3. 启动后有 60 秒：按 Alt + Tab 切到游戏。离开太久（2 分钟）会停下，读到的都保留。
F9→F10提示 F9 被占用，不肯开始
  1. 别的程序占了 F9。终端会列出空着的键。
  2. 换一个键启动：
    > uv run python -m wuwa_vision live --identify --panic-key F10
?→✓格子是红色的，或名字是问号
  1. 有些物品图标一模一样，只能靠点击分辨。
  2. 在游戏里点一下这个物品，等扫描页顶部变成 Ready
  3. 点过一次就会记住，下次不用再点。
?→从 Wiki 更新→✓新版本的物品没有名字
  1. 图鉴是旧的：到 更新 → 图鉴 点「从 Wiki 更新」。
  2. 回到游戏，点一下这些物品。
12→15数量不对
  1. 在 库存 里点这个物品。
  2. 点数字直接改，回车保存。
  3. 改过的数字会一直保留，直到下次扫描读到它。
Reading…↓Ready点了物品要等好几秒
  1. 正常：读右边的详情面板约 2.5–3 秒。
  2. 看到 Ready 再点下一个。
✕ blocked by Application Control✓ python -m wuwa_vision「wuwa」或 python 启动不了，提示被策略阻止
  1. 用模块的方式运行，不要用 wuwa：
    > uv run python -m wuwa_vision live --identify
  2. 如果连 python 也被拦：从 python.org 安装 Python 3.12，再重新安装：
    > powershell -ExecutionPolicy Bypass -File setup.ps1
屏幕录制Mac 上什么都截不到
  1. 系统设置 → 隐私与安全性 → 屏幕录制，打开你的终端。
  2. 关掉终端再重新打开，然后检查：
    > uv run python -m wuwa_vision platform
Tailscale手机打不开这个网站
  1. 电脑和手机都装好 Tailscale，登录同一个账号。
  2. 启动时不要加 --local：
    > uv run python -m wuwa_vision serve
  3. 在手机上打开它印出的网址。
WuWa!页面空白，或说页面没有构建
  1. 安装没有完成，重新运行一次：
    > powershell -ExecutionPolicy Bypass -File setup.ps1
  2. 如果你在改代码：
    > cd web && npm run build

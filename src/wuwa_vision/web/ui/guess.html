猜谜

猜出今天的共鸣者。每猜一次，会告诉你哪些资料对得上。

怎么玩
  1. 输入共鸣者的名字（中文、拼音、首字母或英文都可以），选一位来猜。
  2. 每一行是你猜的那位的十项资料：属性、武器、实装版本、出生、所属、专属料理的效果，以及练满要用的周本、首领、特产和敌人掉落材料。
  3. 普通：十项都比。绿色＝相同，黄色＝部分相同（版本的大版本相同；或者料理不是同一道，但有相同的效果），红色＝不同；版本会用箭头告诉你答案更早还是更晚。料理要是同一道才算相同。
  4. 困难：只比八项，没有版本和料理效果；只有绿色和红色。有的共鸣者八项完全相同：全是绿色却没猜对，就换另一位。
  5. 噩梦：同样只比八项，而且格子不上色，只告诉你这一行有几项相同。可以点格子自己做记号（绿、红、清除），记号只是你的笔记，不会帮你判断。结束后你的记号保持原样，格子角上的 ✓ 或 ✗ 告诉你这个记号标对了还是标错了，没做记号的格子不变；没猜出来还会列出答案的八项。
  6. 每日一位，凌晨 4 点换新；难度在当天第一次猜之前选好，之后不能改。猜完还可以玩自由模式，不计入连胜。

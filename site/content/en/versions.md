# Release notes

What each version changed, on each side: the **scanner** and the **server**. A version that changed one side only needs no update on the other. The app's Update › Data › Versions lists only the newest and the ones in use; the rest are here.

How to read it: each version has two boxes, the scanner (the copy on the PC with the game) and the server (the copy on the NAS). A side marked No changes needs no update for that version. A scanner asks its server before every scan; when either side is missing changes of its own the dashboard says so, and only then does 4 更新 Update download anything.

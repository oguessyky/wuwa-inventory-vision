# 版本记录

每个版本改了什么，分成**扫描端**和**服务器**两边。只改了一边的版本，另一边不用跟着更新：程序里的「更新 › 数据 › 版本」只列最新的和正在用的，其余都在这里。

怎么看：每个版本有两格，左边是扫描端（玩游戏的电脑上那份），右边是服务器（NAS 上那份）。写着「没有改动」的那一边，到了这个版本也不用更新。扫描端每次扫描前都会问服务器，两边谁缺了自己的改动，总览会提醒，「4 更新 Update」也只在那时才下载。

## 下载旧版本

有些版本可以在这里下载：扫描端那一格写着它配套的服务器，以及还能和哪些服务器同步。有严重问题的版本不提供下载，会写明原因和该用哪个版本。

旧版本请解压到**单独的文件夹**。要让它用新版本留下的 data 之前，先**备份**那个 data 文件夹：旧版本会把新版本写的数据改坏。之后的版本遇到更新版本写的数据会拒绝打开、不动它，更早的版本不会。

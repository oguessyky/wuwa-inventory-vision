# 安装指南

每个程序包里都有一份自己的指南：解压后最上面的 `START-HERE.html`（Mac 包是 `START-HERE.md`）。这里放的是同一份，不用先下载也能看——先看看要做哪几步，再决定用哪个包。

Windows 和主机的指南每一步都配了图：一个数字、中英文说要做什么，再画出那一步的样子。图是示意，不是哪个软件的截图。Mac 的指南是文字版，因为 Mac 上每一步都在「终端」里，一句话就说清楚。

## 选哪个包

- **只有一台 Windows 电脑：** 完整版（full），一个包里有扫描和全部页面。
- **想在手机上随时看：** 玩游戏的电脑用扫描端（scanner），NAS 或一直开着的机器上放主机（home）。扫描端每次扫完就把结果发给主机，手机打开主机就能看。
- **在 Mac 上玩：** Mac 完整版（mac-full），或者 Mac 扫描端（mac-scanner）配一个主机。

所有程序包都在 [GitHub 发布页](https://github.com/oguessyky/wuwa-inventory-vision/releases/latest)。下载后先右键压缩包 → 属性 → 勾选「解除锁定」，再解压（Windows）。

照着指南做完还有问题，先看[出了问题怎么办](/troubleshooting)；以后要换新版本，见[更新](/update)。扫描端只在主机比它新、而且新版本改过扫描端时才需要更新，双击 `4 更新 Update` 就行。

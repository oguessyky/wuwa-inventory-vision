# 在 Mac 上安装

用库洛官方的 Mac 客户端。在 Mac 上它**只读不点**，不会替你按任何键。

{{zips}}

## 1. 装好 Python

```
brew install python@3.12
```

（还没有 Homebrew：先按 <https://brew.sh> 上的一行命令装好。）

## 2. 安装

解压到一个不会移动的地方，双击 **`1 安装 Setup`**。macOS 说「无法验证开发者」：右键点它 → **打开** → **打开**。

## 3. 允许「屏幕录制」

**系统设置 → 隐私与安全性 → 屏幕与系统录音**，打开「终端」（不是 Python，也不是游戏），然后重开终端。

## 4. 扫描

mac-scanner 先双击 **`2 连接主机 Connect home`**（见[用 NAS 当主机](/home)）。然后双击 **扫描 Scan**，**点一下游戏窗口**，滚动每个分页；扫完回到终端按 **Ctrl+C**。

## 5. 看结果

mac-full：双击 **`3 总览 Dashboard`**，打开 <http://127.0.0.1:4000>。用主机的话，打开主机的地址。

什么都截不到，几乎都是「屏幕录制」没开：见[出了问题怎么办](/troubleshooting)。

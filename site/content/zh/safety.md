# 安全与隐私

## 它只看屏幕

它读的是屏幕上的像素，和你用眼睛看一样。

- 不读内存、不注入、不改游戏文件、不抓网络包。
- 不移动角色、不战斗、不使用、合成、出售或丢弃任何东西。
- Windows 上只在背包这类菜单里工作；Mac 上完全不按键。
- 游戏不在最前面就暂停。

这是非官方的爱好者工具，与库洛游戏无关；用不用由你决定。

## 你的资料

- **玩家 ID 先抹掉**：每张图保存或显示之前，特征码都会被去掉。
- **一切都在你自己的设备上**。没有统计、没有错误报告、没有广告。
- 手机上看是通过**你自己的** Tailscale 网络，绝不公开到互联网。
- 扫描端发给主机的只有读出的数据和物品小图，**绝不包括整幅画面**。

## 什么时候联网

只在你按了按钮的时候：更新图鉴（库洛官方 Wiki、GitHub 数据表）、安装、你自己的 Tailscale、更新扫描端（本项目的 GitHub）。

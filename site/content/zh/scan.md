# 怎么扫描

你在游戏里滚动背包，它从屏幕上读每一格。它不按键、不动角色，只看屏幕。

## 开始

1. 双击 **`扫描 Scan`**，60 秒内按 **Alt + Tab** 切到游戏（Mac 上点一下游戏窗口）。
2. 打开背包。浏览器会打开扫描页，顶部横条告诉你什么时候能动：**Ready（绿）** 可以滚动或点击，**Reading…（黄）** 等一下。

![扫描页：每一格一个方框，各分页的进度](screens/live.png)

## 滚动

- 慢慢一页一页地滚，和上一屏至少留一行重叠。
- **武器、补给、资源、素材** 每个分页都滚一遍。读到的数量和游戏顶部的物品数一样，就扫全了。

## 点一下

点一下某样东西，它会从详情面板读出名称和**拥有**数量，最准。约 3 秒，等 **Ready** 再点下一个。点过的会被记住。

标着**待确认**的格子（图标一模一样的东西，或新版本的物品）点一下就好；新物品要先在[更新](/update)里更新图鉴。

## 结束

按 **F9**（Mac 上在终端按 **Ctrl+C**），或在扫描页、手机上连按两下 **Stop the scan**。读到的都会保留。F9 被占用的话见[出了问题怎么办](/troubleshooting)。

有服务器的话，每扫完一个分页就发过去；连不上也照样扫，下次再一起发。

## 用手机看扫描

只有一个屏幕时，扫描页被游戏挡住了，可以改在手机上看进度。

电脑和手机都装上 [Tailscale](https://tailscale.com)，登录同一个账号。

和平时一样双击 `扫描 Scan`。它会印出 `phone page:` 和一个网址，比如 `http://你的电脑.你的网络.ts.net:8713`。扫描页顶部也会显示这个网址和端口。在手机上打开并收藏，以后每次都是这个网址。

手机竖着看进度和要你点的东西，横过来还有方框图。

只有你自己的 Tailscale 设备能打开。手机上只能看进度和结束扫描，不能改别的，也不显示游戏画面，而且只有扫描开着时才能打开。记得把手机的自动锁屏调长一点。打不开的话见[出了问题怎么办](/troubleshooting)。

如果这次只想留在这台电脑上，在程序文件夹里运行：

```
uv run python -m wuwa_vision live --identify
```

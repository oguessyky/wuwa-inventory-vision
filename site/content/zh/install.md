# 在 Windows 上安装

**full** 程序包：扫描和全部页面都在这一台 Windows 电脑上。想电脑关着也能用手机看，改看[用 NAS 当服务器](/server)。

**解压之前**：右键点 zip → **属性** → 勾选 **解除锁定**。解压到一个短路径（比如 `C:\wuwa-vision`），之后别移动它。

## 想在手机上看？

电脑和手机都装上 [Tailscale](https://tailscale.com)，登录同一个账号，「总览」窗口启动时会印出手机能打开的网址。电脑关着也想看，就用[服务器](/server)。

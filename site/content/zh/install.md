# 在 Windows 上安装

这一页讲 **full** 程序包：扫描和页面都在同一台 Windows 电脑上。想用手机随时看，请看[用 NAS 当主机](/home)。

## 1. 下载

到 [GitHub 发布页](https://github.com/oguessyky/wuwa-inventory-vision/releases/latest)，下载 `wuwa-inventory-vision-<版本>-full.zip`。

**解压之前：** 右键点下载的 zip → **属性** → 勾选底部的 **解除锁定** → 确定。不这样做的话，Windows 会对里面每个文件都弹出「打开文件 - 安全警告 ... 未知发布者（Unknown Publisher）」。如果还是弹出来，可以放心点 **运行**：这些都是程序包自己的文件。

把它解压到一个短一点的路径，比如 `C:\wuwa-vision`，之后就别再移动这个文件夹（安装会用到里面自带的 Python，移动了就要重新安装）。

## 2. 安装（只需一次）

双击文件夹里的 **`1 安装 Setup`**。它会说明找到了什么，并在每一步之前问你：

- 安装需要的软件包（会按你的显卡选合适的 PyTorch）；
- 下载识别模型（约 346 MB）；
- 从库洛官方 Wiki 下载物品图鉴（几分钟）。

Python 已经包含在程序包里，不用另外装。想全部用默认选项、不再问，可以在 PowerShell 里运行：

```
powershell -ExecutionPolicy Bypass -File setup.ps1 -Yes
```

## 3. 扫描背包

双击 **`2 扫描 Scan`**。然后：

1. 按 **Alt + Tab** 切到游戏，打开背包。
2. 一页一页地慢慢往下滚，每个分页（武器、补给、资源、素材）都滚一遍。
3. 想读准某样东西的数量，就在游戏里点它一下。
4. 扫完按 **F9**。读到的东西都会保留。

扫描时浏览器会打开一个扫描页，显示它正在读什么、哪些分页还没扫。更多技巧见[怎么扫描](/scan)。

## 4. 看结果

双击 **`3 总览 Dashboard`**，然后在浏览器打开 <http://127.0.0.1:4000>。这个窗口开着的时候页面就能用。

第一次打开时，有一个简短的新手引导带你看一遍「总览」。各个页面的说明见[各个页面](/pages)。

![总览](screens/dashboard.png)

## 想在手机上看？

电脑和手机都装上 [Tailscale](https://tailscale.com) 并登录同一个账号，「总览」窗口启动时就会印出一个手机也能打开的网址。如果想手机随时都能看（电脑关着也行），请改用[主机](/home)。

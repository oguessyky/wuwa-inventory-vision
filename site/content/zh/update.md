# 更新

要更新的有两样：**图鉴**（游戏的新物品、新角色）和**程序**。

## 游戏更新后：图鉴

**更新 → 图鉴 → 从 Wiki 更新**。只下载新的部分，页面显示进度和剩余时间。有主机的话只在主机上更新，扫描端扫描前会从主机拿。

## 程序

| 你用的 | 怎么更新 |
|---|---|
| 主机（NAS） | Docker 应用里对项目按 **更新**，数据不动 |
| 扫描端 | 总览说要更新时，双击 **`4 更新 Update`** |
| 一台电脑（full） | 解压新版本到新文件夹，把旧的 `data` 移过去，双击 **`1 安装 Setup`** |

不是每个版本都要更新扫描端：有的只改了主机。扫描端每次扫描前会问主机，**更新 → 数据 → 版本** 也列出每个版本改了哪一边。

`4 更新 Update` 只在主机比它新、而且有扫描端的改动时才动作：从本项目的 GitHub 下载主机那个版本，核对校验值，`data` 不动。

## 两边版本对不上？

只有同步的数据格式变了，两边才会拒绝同步并说「两边的版本不一样」。把两边更新到同一个版本就好。

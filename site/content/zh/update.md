# 更新

要更新的有两样：**图鉴**（游戏每次更新后的新物品、新角色）和**程序本身**。

## 游戏更新后：更新图鉴

到 **更新 → 图鉴**，点 **从 Wiki 更新**。它会从库洛官方 Wiki 下载新增的物品、图片、配方和角色资料，只下载新的部分。页面会显示进行到哪一步、大约还要多久。

有主机的话，只要在主机上更新；扫描端每次扫描前会从主机拿最新的图鉴。

第一次下载（新主机）比较久，以后每次只拿新增的，快很多。

## 更新程序

### 主机（NAS）

在 NAS 的 Docker 应用里，对 `wuwa-inventory-vision` 项目点 **更新**：会拉取最新的镜像，数据不会动。

### 扫描端

不是每个版本都要更新扫描端：有的版本只改了主机。扫描端每次扫描前会问主机，并告诉你：

- 「主机较新，但没有扫描端的改动：扫描端不用更新」；或者
- 「建议更新扫描端」，以及缺了什么。

需要更新时，双击扫描端文件夹里的 **`4 更新 Update`**。它只在主机比它新、而且有扫描端的改动时才会动作：从本项目的 GitHub 发布页下载**主机那个版本**，核对校验值，装到原来的文件夹里（`data` 不动），再重新安装一次。

主机的 **更新 → 数据 → 版本** 列出了每个版本改了哪一边；**总览** 也会在扫描端需要更新时提醒你。

### 只有一台电脑（full）

下载新版本，解压到一个新文件夹，把旧文件夹里的 `data` 文件夹移过去（你的扫描、名字、设置都在里面），然后在新文件夹里双击 **`1 安装 Setup`**。

## 两边版本对不上？

只有在两个版本之间传送的数据格式变了，扫描端和主机才会拒绝同步，并说「两边的版本不一样」。这时把两边都更新到同一个版本就好。其他时候，不同版本也能正常同步。

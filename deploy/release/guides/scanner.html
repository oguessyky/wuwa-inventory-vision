WuWa Inventory Vision · 扫描器 scanner v{version}

在有游戏的电脑上读背包，发到你的服务器。只读屏幕，不碰游戏文件。

Reads the bag on the PC with the game and sends it to your server. Screen pixels only; the game's files are never touched.

1解压之前，先解除锁定Before unzipping, unblock the zip

右键下载的压缩包 → 属性 → 勾选最下面的 解除锁定 → 确定。只做这一次，里面的文件就全都解开了，不用一个一个弄。没有这个勾选框，就是已经解开了。

Right-click the downloaded zip → Properties → tick Unblock at the bottom → OK. Once is enough: every file in it is then clear, with none to do by hand. No such box means it is clear already.

2解压到一个不会再动的地方Unzip it somewhere it stays

例如 C:\wuwa-scanner。安装会用到里面的 Python，以后搬走文件夹就要重新安装。

Such as C:\wuwa-scanner. The setup builds on the Python inside it, so a folder moved later means setting up again.

3如果文件被拦下（没有就跳过）If a file is blocked (skip this if not)

没解除锁定就运行 .cmd，新版 Windows 11 的「智能应用控制」(Smart App Control) 才会弹出下图。它没有“运行”按钮，也不用关掉它。旧一点的 Windows 只问一句（“未知发布者 / Unknown Publisher”），按“运行”就行。下面任选一种：

Running a .cmd without unblocking it is what brings up Smart App Control on a new Windows 11, drawn here. It has no Run button, and it need not be turned off. Older Windows only asks ("Open File - Security Warning ... Unknown Publisher"): Run is safe there. Any one of these:

1

重来，最省事：还没扫描过的话，里面没有你的数据。删掉解压出来的文件夹，解除锁定压缩包，再解压一次。

Start again, the easiest. No scan done yet means nothing of yours is in there: delete the unzipped folder, unblock the zip and unzip again.

2

一个一个来：右键被拦下的文件 → 属性 → 勾选解除锁定 → 确定，每个 .cmd 都做一次。

One at a time: right-click the blocked file → Properties → tick Unblock → OK, for each .cmd.

还是不放心？代码是公开的，可以让 Codex 这类 AI 编程工具帮你看一遍（免费的 ChatGPT 账号也能用，额度有限，以 OpenAI 的说明为准）。请在第一次扫描之前，对刚解压的文件夹做：这类工具会把读到的内容发给它的公司，而这时文件夹里还没有你的数据。

Still not sure? The code is public, so an AI coding tool such as Codex can read it for you (a free ChatGPT account can use it, within limits that change: see OpenAI's page). Do it on the freshly unzipped folder, before the first scan: such a tool sends what it reads to its company, and nothing of yours is in the folder yet.

4双击 1 安装 SetupDouble-click 1 安装 Setup

它会说找到了什么，每一步都先问（按 Enter 就是“是”）。装依赖、显卡对应的 PyTorch 和识别模型；图鉴由服务器发过来，这里不用下。最后分别问要不要在桌面、开始菜单放快捷方式。

It says what it found and asks before each step (Enter is yes): the packages, the PyTorch for your GPU and the recognition model. The catalogue comes from the server. Last, it asks about shortcuts, one place at a time: the Desktop, the Start menu.

5双击 2 连接服务器 Connect serverDouble-click 2 连接服务器 Connect server

先从 NAS 下载服务器的 data/server.key（放在「下载」文件夹）。地址直接按回车就是 wuwa-server，钥匙也直接按回车：会从「下载」里自己找。也可以贴上钥匙那一行。只要做一次。连接后会先下载图鉴（约 50 MB），等它显示 fetched 再关窗口。

First download the server's data/server.key from the NAS (it lands in Downloads). For the address, Enter alone takes wuwa-server; for the key, Enter alone takes server.key from Downloads (pasting its one line works too). Once. After connecting it fetches the catalogue (about 50 MB): wait for fetched before closing the window.

6双击 3 扫描 ScanDouble-click 3 扫描 Scan

然后 Alt-Tab 切到游戏，打开背包，一页一页慢慢滚；点一下物品，名字和数量从详情读。按 F9 结束，读到的都会留下。每个标签扫完就发到服务器。

Then alt-tab into the game, open the bag and scroll each tab a page at a time; click an item to read its name and count. F9 stops, and everything read is kept. Each tab goes to the server as soon as it is finished.

7在服务器上看结果See it on the server

在手机上打开服务器的地址：总览、库存、材料……都是刚扫的。

Open the server's address on your phone: 总览, 库存, 材料… as just scanned.

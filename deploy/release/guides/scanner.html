WuWa Inventory Vision · 扫描器 scanner v{version}

在有游戏的电脑上读背包，发到你的服务器。只读屏幕，不碰游戏文件。

Reads the bag on the PC with the game and sends it to your server. Screen pixels only; the game's files are never touched.

1解压到一个不会再动的地方Unzip it somewhere it stays

例如 C:\wuwa-scanner。安装会用到里面的 Python，以后搬走文件夹就要重新安装。

Such as C:\wuwa-scanner. The setup builds on the Python inside it, so a folder moved later means setting up again.

解压之前：右键下载的压缩包 → 属性 → 勾选最下面的 解除锁定 → 确定。否则 Windows 会对每个文件问一次（“打开文件 - 安全警告 … 未知发布者 / Unknown Publisher”）。真的问了也没关系，按“运行”：这些都是这个包自己的文件。

Before unzipping: right-click the downloaded zip → Properties → tick Unblock at the bottom → OK. Otherwise Windows asks about each file ("Open File - Security Warning ... Unknown Publisher"); if it does, Run is safe: the files are this package's own.

2双击 1 安装 SetupDouble-click 1 安装 Setup

它会说找到了什么，每一步都先问（按 Enter 就是“是”）。装依赖、显卡对应的 PyTorch 和识别模型；图鉴由服务器发过来，这里不用下。最后问要不要在桌面和开始菜单放快捷方式。

It says what it found and asks before each step (Enter is yes): the packages, the PyTorch for your GPU and the recognition model. The catalogue comes from the server. Last, it offers shortcuts on the Desktop and in the Start menu.

3双击 2 连接服务器 Connect serverDouble-click 2 连接服务器 Connect server

先从 NAS 下载服务器的 data/server.key（放在「下载」文件夹）。地址直接按回车就是 wuwa-server，钥匙也直接按回车：会从「下载」里自己找。也可以贴上钥匙那一行。只要做一次。

First download the server's data/server.key from the NAS (it lands in Downloads). For the address, Enter alone takes wuwa-server; for the key, Enter alone takes server.key from Downloads (pasting its one line works too). Once.

4双击 3 扫描 ScanDouble-click 3 扫描 Scan

然后 Alt-Tab 切到游戏，打开背包，一页一页慢慢滚；点一下物品，名字和数量从详情读。按 F9 结束，读到的都会留下。每个标签扫完就发到服务器。

Then alt-tab into the game, open the bag and scroll each tab a page at a time; click an item to read its name and count. F9 stops, and everything read is kept. Each tab goes to the server as soon as it is finished.

5在服务器上看结果See it on the server

在手机上打开服务器的地址：总览、库存、材料……都是刚扫的。

Open the server's address on your phone: 总览, 库存, 材料… as just scanned.

WuWa Inventory Vision · 主机 home v{version}

家里一直开着的机器上的总览：用现成的镜像，在 NAS 的 Docker 应用里粘贴一个文件就部署，不用编译、不用 SSH、不用下载压缩包。

The dashboard on a box that is always on: a ready-made image, deployed from the NAS's Docker app from one pasted file -- nothing to build, no SSH, no zip.

1拿一把 Tailscale 钥匙Get a Tailscale auth key

打开 Tailscale 的 Keys 页，按 Generate auth key，复制出来的 tskey-auth-…。一次性的就够了：只在第一次启动用。别给别人看。

Open Tailscale's keys page, press Generate auth key and copy the tskey-auth-…. A one-off key is enough: it is used once, on the first start. Keep it to yourself.

2在 Docker 应用里建项目Create the project in the Docker app

NAS 的 Docker 应用 → Project → Create project：名称 wuwa-inventory-vision；存储路径选一个空文件夹（数据就放在里面）；Compose configuration 粘贴整个 docker-compose.yaml（在发布页或这个文件夹里），把 tskey-auth-PUT-YOURS-HERE 换成你的钥匙 → Deploy。

The NAS's Docker app → Project → Create project: name it wuwa-inventory-vision; for the storage path pick an empty folder (the data is kept there); under Compose configuration paste the whole docker-compose.yaml (on the release page, or in this folder) and put your key over tskey-auth-PUT-YOURS-HERE → Deploy. With plain Docker, the key may go in a .env instead.

3打开它Open it

在登录了同一个 Tailscale 的手机或电脑上打开 http://wuwa-home.<你的 tailnet>.ts.net:4000。

On a phone or PC signed in to the same tailnet, open http://wuwa-home.<your tailnet>.ts.net:4000.

4第一次：拉取图鉴The first time: fetch the catalogue

全新的主机还没有图鉴：没有物品名、图、食谱和养成表。打开它的 更新 页，按 从 Wiki 更新，从库洛官方 Wiki 下载（几分钟，页面会显示进度）。扫描器每次扫描前从主机拿图鉴，所以要在第一次扫描之前做。

A home started from nothing has no catalogue yet: no item names, pictures, recipes or builds. Open its 更新 page and press 从 Wiki 更新; it downloads Kuro's official catalogue (a few minutes, the page shows how far). Scanners take it from the home before each scan, so do it before the first scan.

5关掉钥匙过期Turn off key expiry

Tailscale 的 Machines 页里会多一台 wuwa-home：点 … → Disable key expiry，否则半年后要重新登录。

A wuwa-home appears on Tailscale's machines page: … → Disable key expiry, or it asks to log in again in six months (key expiry).

6连接扫描器Connect a scanner

扫描器要的钥匙是存储路径里 data/home.key 那一行（NAS 的文件管理器能打开）。在装了扫描器的电脑上双击 2 连接主机 Connect home：地址直接按回车就是 wuwa-home，再贴上钥匙。

The key a scanner needs is the one line of data/home.key in the storage path (the NAS's file manager opens it). On the PC with the scanner, double-click 2 连接主机 Connect home: Enter alone takes wuwa-home for the address; then paste the key.

7更新Updating

在 Docker 应用里对这个项目按 Update：拉下新镜像，数据不动。扫描器也更新到同一版本。

Press Update on the project in the Docker app: the new image is pulled and the data stays. Update the scanner to the same version.

8在旁边试新版Try a version beside the one you have

再建一个项目，名称 wuwa-inventory-vision-test、另一个空文件夹，粘贴同一个文件，只改一个词：TS_HOSTNAME 那行的 wuwa-home 改成 wuwa-home-test。它是 Tailscale 里另一台设备、另一份数据，不影响原来的。

A second project, wuwa-inventory-vision-test, in another empty folder, with the same file and one word changed: wuwa-home in the TS_HOSTNAME line, to wuwa-home-test. Another device on the tailnet with its own data; the first is untouched.

9从旧的主机搬过来Moving from the old home

旧的主机（自己编译的那种）的数据都在它的数据文件夹里：扫描、改过的名字、目标、底数、规划、抽卡记录和 home.key。按下面的顺序搬，什么都不会丢。

Everything the old home (the one built from source) has is in its data folder: scans, names, targets, base amounts, plans, the pull history and home.key. Move it in this order and nothing is lost.

  1. 在 Docker 应用里停掉旧项目——先别删。
  2. 在新项目要用的空文件夹里建 seed-data/，把旧的数据文件夹（旧项目 .env 里的 WUWA_DATA）里的东西整个复制进去。
  3. 按上面 1–3、5 建新项目：第一次启动会把 seed-data 收进来，图鉴也在里面，第 4 步不用做。
  4. 打开新地址，确认数据都在。home.key 也搬过来了，钥匙不变：扫描器只要用 2 连接主机 换成新地址。
  5. 都没问题了，再删掉旧项目。
  1. Stop the old project in the Docker app -- do not delete it yet.
  2. In the empty folder the new project will use, make seed-data/ and copy into it everything in the old data folder (WUWA_DATA in the old project's .env).
  3. Create the new project (1–3 and 5 above): its first start takes seed-data in, the catalogue with it, so step 4 is not needed.
  4. Open the new address and check your data is there. home.key came along, so the key is the same: a scanner only needs the new address (2 连接主机).
  5. When all is well, delete the old project.

没复制数据就删旧项目，扫描以外的东西（改过的名字、目标、规划）都会没有。

Delete the old project without copying its data and what only it held -- names given on a phone, targets, plans -- is gone.

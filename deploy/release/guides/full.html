WuWa Inventory Vision · 完整版 full v{version}

一台电脑上全都有：扫描器和总览。只读屏幕，不碰游戏文件，数据都在你自己电脑上。

Everything on one PC: the scanner and the dashboard. Screen pixels only, and everything stays on your own computer.

1解压到一个不会再动的地方Unzip it somewhere it stays

例如 C:\wuwa-vision。安装会用到里面的 Python，以后搬走文件夹就要重新安装。

Such as C:\wuwa-vision. The setup builds on the Python inside it, so a folder moved later means setting up again.

解压之前：右键下载的压缩包 → 属性 → 勾选最下面的 解除锁定 → 确定。否则 Windows 会对每个文件问一次（“打开文件 - 安全警告 … 未知发布者 / Unknown Publisher”）。真的问了也没关系，按“运行”：这些都是这个包自己的文件。

Before unzipping: right-click the downloaded zip → Properties → tick Unblock at the bottom → OK. Otherwise Windows asks about each file ("Open File - Security Warning ... Unknown Publisher"); if it does, Run is safe: the files are this package's own.

2双击 1 安装 SetupDouble-click 1 安装 Setup

它会说找到了什么，每一步都先问（按 Enter 就是“是”）：依赖、显卡对应的 PyTorch、识别模型，还有从库洛官方 Wiki 下载的图鉴（几分钟）。最后问要不要在桌面和开始菜单放快捷方式。

It says what it found and asks before each step (Enter is yes): the packages, the PyTorch for your GPU, the recognition model, and the catalogue from Kuro's wiki (a few minutes). Last, it offers shortcuts on the Desktop and in the Start menu.

3双击 2 扫描 ScanDouble-click 2 扫描 Scan

然后 Alt-Tab 切到游戏，打开背包，一页一页慢慢滚；点一下物品，名字和数量从详情读。按 F9 结束，读到的都会留下。

Then alt-tab into the game, open the bag and scroll each tab a page at a time; click an item to read its name and count. F9 stops, and everything read is kept.

4双击 3 总览 DashboardDouble-click 3 总览 Dashboard

在浏览器打开 http://127.0.0.1:4000。窗口开着页面就在；关掉窗口就停。

Open http://127.0.0.1:4000 in a browser. The pages run while its window is open; close it to stop them.

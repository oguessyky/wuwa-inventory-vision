WuWa Inventory Vision · Mac 完整版 mac-full v{version}

一台 Mac 上全都有：扫描和页面。用库洛官方的 Mac 客户端；只读屏幕，不碰游戏文件。

Everything on one Mac: the scanner and the pages. With Kuro's own Mac client; screen pixels only, the game's files never touched.

1解压到一个不会再动的地方Unzip it somewhere it stays

例如个人文件夹里的 wuwa-vision。以后搬走文件夹就要重新安装。

Such as wuwa-vision in your home folder. A folder moved later means setting up again.

2装好 Python 3.12Install Python 3.12

打开「终端」，运行 brew install python@3.12。还没有 Homebrew 的话，先按 brew.sh 上的一行命令装好。

Open Terminal and run brew install python@3.12. No Homebrew yet? Its one line is on brew.sh.

3双击 1 安装 SetupDouble-click 1 安装 Setup

第一次 macOS 会说「无法验证开发者」：右键点它 → 打开 → 再点 打开。然后它会说找到了什么，每一步都先问（按 Enter 就是“是”），包括从库洛官方 Wiki 下载的图鉴。最后分别问要不要在桌面、「应用程序」（启动台、聚焦搜索）放快捷方式。

The first time, macOS says it cannot verify the developer: right-click it → Open → Open. Then it says what it found and asks before each step (Enter is yes), the catalogue from Kuro's wiki among them. Last, it asks about shortcuts, one place at a time: the Desktop, Applications (Launchpad, Spotlight).

4允许「屏幕录制」Allow Screen Recording

macOS 不让任何程序读别的窗口，除非你同意：系统设置 → 隐私与安全性 → 屏幕与系统录音，打开「终端」（不是 Python，也不是游戏），然后关掉终端再打开。

macOS lets no program read another's window unless you agree: System Settings → Privacy & Security → Screen & System Audio Recording, turn on Terminal (not Python, not the game), then quit and reopen Terminal.

5双击 2 扫描 ScanDouble-click 2 扫描 Scan

点一下游戏窗口：在 Mac 上只有点进去的窗口才算在最前面。打开背包，慢慢滚每个分页；扫完回到终端按 Ctrl+C。在 Mac 上它只读不点，不会替你按任何键。

Click the game window: on a Mac only the window clicked into is in front. Open the bag and scroll each tab slowly; when done, press Ctrl+C in Terminal. On a Mac it only reads: it never presses a key for you.

6双击 3 总览 DashboardDouble-click 3 总览 Dashboard

在浏览器打开 http://127.0.0.1:4000。窗口开着页面就在；关掉窗口就停。

Open http://127.0.0.1:4000 in a browser. The pages run while its window is open; close it to stop them.
